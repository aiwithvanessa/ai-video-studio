# Maintained editing workflow

The coding agent uses the shipped implementation; it does not regenerate an editor for each recipient. Future delivery starts from BOOTSTRAP-PROMPT.md in an empty folder with a real pinned release URL/hash. That public release does not exist yet. Internal development uses this maintained candidate directly.

0. Follow [low-friction permissions](../.agents/skills/ai-video-studio/references/permission-workflow.md). Verify the studio is in the active declared writable scope; a different cwd is insufficient. Correct an external-folder mismatch once before editing. Authorized draft work proceeds with default sandbox permissions; no per-caption/effect/brief/render consent questions. Summarize required setup downloads together, reuse completed tools/state, and respect actual platform restrictions. Brand/final-export review remains.
1. Read AGENTS and the project skill. Resume local state via node scripts/studio.mjs status; setup helpers inspect availability without global configuration. Required system prerequisites: Windows x64, suitable Node/npm and FFmpeg/ffprobe. npm ci installs the exact lockfile. Check actual versions/permissions; a failed lookup may be PATH or access, not missing software. Node 24 is the development baseline; clean Windows is not yet certified.
2. Follow [identity and reference onboarding](../.agents/skills/ai-video-studio/references/onboarding.md), including the explicit optional reference offer, evidence/limitations, reusable style direction and motion review before approval. Preserve prior identity approvals while missing style review resumes. Follow the short conversation reference: offer website/materials first, invite 1–3 reference attachments in a separate question, then review style. No required name/audience/tone questionnaire. Immediately invite footage after style approval. Optional website/materials inform proposed choices. The agent inspects accessible links/files, never assumes another chat's attachments. Use studio brand options to populate the actual BrandPreview composition. Present its Studio URL, then approve-brand only with actual user approval evidence. Logo/fonts/reference materials are optional; do not block the basic workflow.
3. Choose a video ID and run studio new-video. The helper creates folders and a brief; the agent maintains it from conversation. Follow the skill’s automatic media import instructions: verify readable attachment originals or accept a full local path, run studio import-media, then studio intake using its returned public-relative asset. Handle naming/folders/briefs internally, preserve originals, and wait only for essential inaccessible footage. Before the first draft, use the host question box (or short chat fallback) for an optional opening hook, target length and editing instructions; record already supplied answers without asking again using studio brief. It probes source metadata, preserves source audio/proportions and selects at most the requested first section (default 15 seconds) at 30fps with bounded even dimensions. Other videos' files are not borrowed automatically.
4. For English captions/cleanup run the maintained `studio prepare-speech <id> --language en` path (add --setup true after disclosing required CPU model/runtime downloads when missing). This executes recognition, acoustic word alignment, strict validation and import; it resumes preserved recognition after alignment failure and reuses valid current speech data. Raw numeric/phrase estimates cannot pass caption-render or cleanup guards. No clamping, global shifts or invented boundaries. Other languages/failed preparation need a clear blocker; use an explicitly uncaptioned, uncut preview rather than unsafe cuts or fake captions. Engine/models/licences stay in ignored .local, never in releases.
For requested raw-take cleanup follow the skill’s take-cleanup reference after full-section transcription and before effects/graphics. The detector is conservative; Codex supplies and reports semantic take choices. Apply reversible cuts and mapped captions, then review the playable result.

5. Review mistakes in ordinary language. The agent creates a correction patch with base hash, expected text/index and a review note, uses review-transcript.mjs to create a separate reviewed asset, then imports it. Never overwrite automatic/older reviewed results or suppress profanity/repetitions. Text/time JSON editing is the agent's job, not a required beginner exercise.
6. The maintained EditedVideo composition, Captions, Graphics and Effects components handle footage/title/captions, callouts/steps/screenshots, optional highlighting and restrained zoom/pan/fade. The agent chooses useful content/timing, configures via studio commands and records significant graphics/effects in the brief for Approve/Request changes. Real screenshots are required for product demos; no invented claims/UI. Default placement needs inspection against actual faces/captions. Add original reusable components only for a genuine missing edit requirement, not a competing system.
7. Only verified/approved starter-pack sounds may be configured; empty pack is fine. No personal sound or automatic music. Any actual mix needs listening/level checks.
8. studio preview selects the actual composition and starts its own free local port, checks HTTP and prints URL/restart command. Keep the terminal running. Studio is playable preview; studio draft also renders a clearly named draft MP4. Report browser/media access or listening limits honestly. The agent runs typecheck/check/check:editing and relevant media checks, not the beginner.
9. Translate revisions into studio set/effect/graphic commands. Titles can be resized and effects/graphics removed by ID without cutting underlying footage/audio. Changes clear approval. Brand changes invalidate video approvals too. Direct source/asset changes are detected by the final export fingerprint.
10. After explicit approval of the identified current draft, approve-video records note/revision/fingerprint. studio export enforces current brand and video approval, renders H.264/yuv420p with concurrency 1 and conservative extraction limits, probes metadata/audio and refuses mismatches. It never silently overwrites a previous export. Final approval gates are implemented in the wrapper; raw Remotion CLI still exists and must not be used to bypass them.

Commands and limits are in the skill capability register. Current implementation is a single-source section editor, not an arbitrary multi-track nonlinear editor; Codex interprets brand materials and edit intent. CTC acoustic alignment is implemented for English, but model scores and structural checks are not a listening certificate. No public release or cross-platform claim is made.
# Script-assisted cleanup

Offer an optional attached/pasted script with the edit instructions. Import and compare through `studio script-import` / `studio script-analyze`; the agent handles paths. Keep scripts distinct from automatic recognition and reviewed caption data. Allow paraphrases, check complete alternate takes throughout the recording, and preserve unique points. A script is not forced alignment: text comparison cannot certify sentence cuts or caption synchronization. See the skill's script-assisted review reference for commands and remaining limits.
