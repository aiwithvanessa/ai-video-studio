# Match the supplied reference, not a house template

When references are supplied, the default goal is close stylistic imitation of typography, caption treatment, placement, graphic hierarchy and layout. Brand colours and explicit user choices take priority. Preserve the reference's structural character; do not replace it with generic large numbers or black caption panels. Never copy the creator's words, logos, product UI, footage or sounds into the recipient's new content. Multiple references: name a primary reference; combine specific features only when compatible, asking one focused question if they conflict materially.

Analyze actual accessible video. Record sample times/method and uncertainty for: font category/likely available family, weight, case, approximate size as frame-width ratio, outline versus shadow versus backing, alignment, caption position/margins, line count, words per phrase, highlight behaviour, title hierarchy, presenter/graphic proportions and shot rhythm. Inspect dense frame sequences or playback for motion; a sparse contact sheet does not establish transition timing or audio. Outline is not a black box. Unknown fonts/animation must be labelled approximations, not confidently identified. Use the closest locally available licensed font; don't download or bundle creator fonts without verified rights.

Convert evidence into runtime settings, not only prose. style-plan with supplied references now requires referenceMatch {referenceAsset, previewLayout: presenter|stacked|graphic, headingFontFamily, headingWeight, headingSizeRatio, deviations: string[]} and an explicit captionAppearance (fontFamily, fontWeight, fontSizeRatio, bottomRatio, wordsPerPhrase, maxLines, strokeWidthRatio, backing and colours). Optional sideMarginRatio, align, lineHeight, letterSpacingRatio, strokeColor and frame-driven entrance/entranceFrames are supported. Ratios use frame width except bottomRatio, which is frame height. Font metrics may require smaller phrasing rather than automatic shrinking; inspect at phone size. Bind the primary asset to the analyzed imported file. Existing approved projects remain unchanged until a new style proposal is made.

ReferenceStylePreview demonstrates these settings with original text/cards and a clearly labelled footage placeholder. It replaces the generic large-number sample for supplied references. It currently supports presenter, stacked graphic/presenter and full-graphic demonstrations; it is NOT an implementation of every possible reference layout or a multi-track editor. If the reference needs a different major treatment, adapt this original preview with existing components before claiming a match. Caption settings are shared by preview and edited footage; stacked layout is currently a style-preview capability, not proof that the footage editor already switches scene layouts. Build missing layout behaviour during an authorized edit when required.

Review gate: inspect reference and sample side by side using representative frames AND the rendered sample. Compare caption type/weight/size/position/outline/backing, title hierarchy, scene proportions and assessed motion. List each intentional brand change and remaining limitation. Preserve still-unassessed sound as unassessed. If the preview still resembles the default instead of the reference, revise it before seeking approval. Do not describe it as an exact match based solely on structural checks or a successful render. Ask for plain-language visual changes, then retain the usual style approval and immediate footage invitation.

When no references are provided, use the polished default. Do not force reference upload or a technical questionnaire just to configure these fields: the agent measures/sets them internally.

Additional measured preview controls: referenceMatch.headingTopRatio (frame-height fraction), splitRatio (presenter/graphic boundary), graphicBackground (hex) and gridSizeRatio (frame-width fraction). Set these from the primary reference; do not confuse a roughly similar preset with a measured match. Placeholder footage and original demonstration cards are explicit deviations.

Caption placement must be matched per layout/shot, using multiple reference frames. Do not apply one stacked-layout position to every scene. captionAppearance.centerYRatio anchors the caption block centre in frame-height units and overrides bottomRatio; inspect visible glyph bounds since font metrics can still differ by pixels. referenceMatch.previewScenes may contain ordered nonoverlapping {start,end,layout,captionCenterYRatio} entries for the eight-second sample. These are agent-managed demo settings, not offsets to speech timestamps. Captions accepts captionCenterYRatio per scene for reuse; actual editing layouts must deliberately supply it when their scene changes.
